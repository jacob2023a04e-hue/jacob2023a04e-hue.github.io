Seção 2 — Ranking de Tecnologias

  1. HTML

    Linguagem responsável pela estrutura das páginas web.

  2. CSS

    Utilizado para estilizar e organizar visualmente os elementos da página.

  3. JavaScript

    Linguagem que adiciona interatividade às aplicações web.

  4. React

    Biblioteca JavaScript bastante utilizada para construção de interfaces.

  5. Node.js

    Plataforma que permite executar JavaScript no servidor.

Seção 3 — Glossário de Termos Técnicos

HTML
Linguagem de marcação utilizada para estruturar páginas web.
CSS
Linguagem utilizada para estilização de páginas web.
JavaScript
Linguagem de programação voltada para interatividade em páginas web.
Pode ser utilizada tanto no frontend quanto no backend.
DOM
Estrutura que representa os elementos de uma página HTML.
API
Interface utilizada para comunicação entre sistemas.
Pode fornecer dados ou funcionalidades para aplicações.
HTTP
HTTPS
Protocolos utilizados para comunicação na web.
URL
Endereço Web
Localização utilizada para acessar recursos na internet.
DNS
Sistema responsável por traduzir nomes de domínio em endereços IP.
